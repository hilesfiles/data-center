# Application release 1.52 — Batch 4 project audits

Application release 1.52 advances the generated study data to `private-sector-study-1.49.0` and publishes the reconciled Batch 4 audits for State Farm Olathe, Google The Dalles, and Switch Las Vegas NAP7.

The batch adds 26 source records: 22 reported observations and four source projections. Only three separately governed syntheses are added, all low-confidence descriptive county benchmarks for The Dalles after project-specific public-source searches were exhausted. State Farm Olathe and Switch NAP7 add no models. The study now contains 718 source records—648 reported and 70 projected—and 149 modeled syntheses. Fifteen completed project audits are map-eligible, while the independent full modeled-account gate remains at three.

Each Batch 4 project contains exactly one factual project description and remains incomplete where supplier payments, same-scope public costs, measured resource use, or causal county outcomes cannot be supported. The project pages render “About this project” above “Why this project is in the study.”

The release preserves the cache-safe community map and direct county-detail links.
