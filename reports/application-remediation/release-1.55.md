# Application release 1.55 — Batch 6 project audits

Application release 1.55 advances the generated study data to `private-sector-study-1.51.0` and publishes the reconciled Batch 6 audits for Google Clarksville, Meta Prineville, and Microsoft Boydton.

The batch adds 162 source records: 133 reported observations and 29 source projections. Six eligible last-resort syntheses are added after direct-evidence discovery, gap closure, and metric-specific modeling review. The study now contains 931 source records—826 reported and 105 projected—and 155 separately governed modeled syntheses. Twenty-one completed project audits are map-eligible, while the independent full modeled-account gate remains at three.

Clarksville adds exact-account appraisal and ordinary-tax-levy histories, grant evidence, and a bounded water-consumption identity. Prineville adds current assessor accounts, tax-lot and assessment history, long-range-zone fiscal evidence, fee and permit records, and a water-unit conversion while removing three weak county-comparison models. Boydton adds a portal-by-portal evidence matrix and four bounded fiscal syntheses; other candidate models were rejected with metric-specific reasons where project scope, non-overlap, or attributable inputs were not defensible.

Each Batch 6 project contains exactly one factual project description. The project pages render “About this project” above “Why this project is in the study.” The release preserves all twenty-one completed-project map markers and direct county-detail links. The six-project corrective model-eligibility audit remains scheduled ahead of Batch 7.
