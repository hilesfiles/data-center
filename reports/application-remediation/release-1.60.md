# Application release 1.60

Application release 1.60 advances the generated study data to `private-sector-study-1.56.0` and publishes the independently audited Apple Maiden, NYSE Mahwah, and Quicken Loans Technology Center / Corktown accounts.

The batch adds 45 source records—40 reported observations and five source projections—and nine separately governed last-resort modeled syntheses. The study now contains 1,091 source records—980 reported and 111 projected—and 125 modeled syntheses. Twenty-seven completed research audits are map-eligible; analytical completeness remains a separate gate and no project currently passes it.

Apple Maiden adds a ten-year campus electricity series, six realized county incentive expenses, investment, employment, permit, grant, and facility-boundary evidence. All Apple model candidates were rejected because the available campus and company/county evidence cannot be defensibly allocated to the selected IM3 building.

NYSE Mahwah adds historical assessments, current paid parcel taxes, a rolling water account, and exact building/customer/later-expansion boundaries. Seven models retain three certified recipient levy allocations, a same-account public-cost break-even threshold, a 28 MW energy sensitivity, a rolling water conversion, and a conditional 24x7 support-coverage floor.

Quicken Corktown resolves the four-predecessor parcel history, separates Rocket-related personal-property accounts, closes the 2018 City subsidy-report trail, and rejects the ambiguous contractor-page value as spend evidence. Two low-confidence models retain a 1.4 MW whole-facility electricity sensitivity and an electrician-only wage-payroll sensitivity; neither is presented as observed use or payroll.

Each project contains exactly one factual project description. The project pages render “About this project” above “Why this project is in the study,” and publication verification covers all completed map markers plus direct project and county navigation.
