# Application release 1.51 — Batch 3 project audits

Application release 1.51 advances the generated study data to `private-sector-study-1.48.0` and publishes the reconciled Batch 3 audits for NTT Silicon Valley SV1, Meta Eagle Mountain, and Meta Henrico.

The batch adds 32 source records: 29 reported observations and three source projections. Eight separately governed modeled syntheses remain only where project-specific public-source searches were exhausted and the inputs, formulas, uncertainty, and limitations could be reproduced. The study now contains 692 source records—626 reported and 66 projected—and 146 modeled syntheses. Twelve completed project audits are map-eligible, while the independent full modeled-account gate remains at three.

Each Batch 3 project contains exactly one factual project description. The descriptions distinguish the individual facility or campus from later phases and broader operator portfolios, and the project pages render “About this project” above “Why this project is in the study.”

The release preserves the cache-safe community-map behavior and direct county-detail links introduced in release 1.50.
