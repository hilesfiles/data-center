# Application release 1.53 — Batch 5 project audits

Application release 1.53 advances the generated study data to `private-sector-study-1.50.0` and publishes the reconciled Batch 5 audits for Flexential Minneapolis-Chaska, Markley Lowell, and Meta Los Lunas.

The batch adds a net 51 source records: 45 reported observations and six source projections. No modeled syntheses are added. The study now contains 769 source records—693 reported and 76 projected—and 149 separately governed modeled syntheses. Eighteen completed project audits are map-eligible, while the independent full modeled-account gate remains at three.

The Flexential audit establishes the mapped project as the former ViaWest adaptive-reuse facility at 3500 Lyman Boulevard. Six incentive-payment rows associated with Stream/IP Stream facilities at 1706 and 1708 West Creek Lane were removed from this project's account instead of being carried forward under an unresolved crosswalk.

Each Batch 5 project contains exactly one factual project description and remains incomplete where supplier payments, same-scope public costs, measured resource use, or causal county outcomes cannot be supported. The project pages render “About this project” above “Why this project is in the study.” The release preserves all completed-project map markers and direct county-detail links.
