# Application release 1.44 — dark map-forward theme

Application release 1.44 gives the Observatory a dark, map-forward visual system inspired by contemporary civic mapping tools. It does not change study release `private-sector-study-1.42.0`, the three completed accounts shown on the map, or any source and modeled data.

The application shell now uses compact navigation, near-black surfaces, restrained borders, high-contrast typography and blue interaction accents. The project register, project profiles, evidence cards, modeled records, fiscal histories and county profiles share the same palette and control treatment. Status colors retain distinct blue, green and amber meanings without presenting benefit or cost as a moral red/green score.

The map uses charcoal county geography, subtle boundary lines, blue completed-study counties and markers, a compact dark legend and dark zoom controls. The redundant overlay attribution control was removed because the permanent map caption already identifies the Census geography and preserved research inventory.

Responsive styling fits all three navigation destinations within the mobile viewport and keeps the map, caption and study controls in a clear vertical sequence. Browser validation checks the theme colors, desktop and mobile overflow, all existing evidence interactions and the three-account map contract.
