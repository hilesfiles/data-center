# Application release 1.56 — Corrective model-audit Batch A

Application release 1.56 advances the generated study data to `private-sector-study-1.52.0` and publishes the corrective model-eligibility audits for Meta Eagle Mountain, State Farm Olathe, and Switch Las Vegas NAP7.

The corrective batch adds seven reported observations and no source projections. Five eligible last-resort syntheses are added only after renewed direct-evidence discovery and candidate-by-candidate eligibility review. The study now contains 938 source records—833 reported and 105 projected—and 160 separately governed modeled syntheses. Twenty-one completed project audits remain map-eligible, while the independent full modeled-account gate remains at three.

Eagle Mountain adds four annual employee counts, one assessed-value observation, and one documented community grant; its detailed model audit rejects all candidate families because the available inputs do not support defensible scope, non-overlap, or attribution. Olathe adds a non-additive state investment record and retains a parcel-payment public-service-cost break-even plus three explicitly descriptive county comparison gaps. NAP7 retains one assessed-liability public-service-cost break-even and explicitly rejects investment, construction, supplier, operations, fiscal, resource, community, and county-outcome candidates that lack building-scoped inputs.

Each project retains exactly one factual project description. The project pages render “About this project” above “Why this project is in the study.” The release preserves all twenty-one completed-project map markers and direct county-detail links.
